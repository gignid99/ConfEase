# ConfEase

ConfEase is a mobile application for seamless conference management. It provides a unified platform for both organizers and attendees to manage and participate in conferences efficiently.

## Features
- Dashboards for monitoring events and engagement  
- Shared calendar for real-time scheduling  
- QR-based contact sharing  
- Media gallery for session photos and videos  
- Event feedback system  
- Common notice board for updates and reminders  

## User Roles
- **Organizer Login** – for creating and managing conferences, posting updates, and viewing analytics  
- **Attendee Login** – for accessing schedules, sharing contacts, and submitting feedback
